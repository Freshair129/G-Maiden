# แบบฟอร์มยินยอมสำหรับ corpus วัดผล Local STT

> Template นี้ใช้สำหรับ corpus ของ CR-044 / MVP-038 เท่านั้น เก็บแบบฟอร์มที่ลงนามแล้วและไฟล์เสียงไว้นอก Git และนอกที่เก็บ source code

## วัตถุประสงค์

ข้าพเจ้ายินยอมให้บันทึกเสียงของข้าพเจ้าเพื่อประเมินความแม่นยำ ความหน่วง และการทำงานแบบ local-only ของ candidate speech-to-text (STT) สำหรับ G-Maiden เท่านั้น การประเมินครอบคลุมตัวอย่างภาษาไทย ภาษาอังกฤษ และ Thai-English code-switch ในสภาวะเงียบและมีเสียงเกมจำลองตามที่ระบุใน manifest

## ขอบเขตการใช้และการเก็บรักษา

- ไฟล์เสียง, transcript, label และ receipt เก็บไว้เฉพาะในเครื่องที่ได้รับอนุญาต และไม่ commit เข้า Git
- จะไม่เผยแพร่ ส่งต่อ ใช้เพื่อ analytics/telemetry หรือส่งไปยังบริการภายนอก
- ชุดข้อมูลนี้ไม่ใช่ฟีเจอร์บันทึกเสียงในแอป และไม่อนุญาตให้ใช้เสียงเพื่อการฝึกโมเดลหรือวัตถุประสงค์อื่น
- ผล benchmark อาจเก็บ transcript ไว้ใน output directory ที่ผู้รันเลือก เพื่อให้ตรวจสอบซ้ำได้; output นั้นต้องคงเป็น local-only
- ผู้เข้าร่วมสามารถขอให้ลบเสียงและข้อมูลที่เชื่อมโยงได้ โดยติดต่อผู้ดูแล corpus ตามข้อมูลด้านล่าง
