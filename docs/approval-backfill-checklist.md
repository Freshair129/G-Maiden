# Approval Backfill Checklist

Generated by **G25-T3** (approval evidence extraction). `node tools/doc-graph/scan.mjs --strict`
flags every `status: accepted|stable` doc that lacks both `approved_by` and `approved_date`
as `missing-approval`. Per the epic's evidence-only rule, `approved_by`/`approved_date` may be
set **only** when the doc body or changelog already contains an explicit sign-off statement
(e.g. "Signed off by Boss ... 2026-07-10", "ตัดสินใจโดย Boss ... 2026-07-19") — a bare
`status: accepted`/`Accepted` label is the claim itself, not evidence for it, and is not
sufficient on its own. **Fabricating `approved_by`/`approved_date` is out of scope — never do
this.** The rows below are the docs where that search came up empty; they need a real sign-off
from Boss (in whatever form — a changelog row, a comment, a reply here) before the fields can be
set honestly.

Two of the original nine `missing-approval` violations **did** have in-doc evidence and were
fixed directly (not listed here): `ADR-16-credit-economy-and-mint-oracle` (body line: "Boss
กำหนดทิศทางไว้ (session 2026-07-10)") and `ADR-18-dev-runtime-governance-split` (body line:
"ตัดสินใจโดย Boss ใน working session 2026-07-19").
