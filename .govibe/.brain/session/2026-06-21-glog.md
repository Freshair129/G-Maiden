## บทเรียน

1. **`std::env::var("LOCALAPPDATA")`** ทำงานปกติบน Windows — ไม่ต้องใช้ `dirs` crate.
2. **Mutex static + single-slot Option<File>** เป็นรูปแบบมาตรฐานสำหรับ "persistent
   state ต่อเซสชัน" — สอดคล้องกับ TTS CURRENT slot. ไม่ต้อง Arc, ไม่ต้อง LazyLock.
3. **Windows file-lock cache lie**: `Get-ChildItem` รายงาน `Length=0` ถ้าไฟล์เปิดค้างใน
   process อื่นแบบ append. `[System.IO.File]::ReadAllBytes` ที่ throw sharing
   violation ให้ดูที่ `$f.Length` หลัง refresh แทน. กับดักสำคัญถ้า debug log file
   ขณะ app ยังเปิด.
4. **GameTick → JSON ผ่าน `serde_json::json!` macro** สะอาดมาก: `{"ts": ..., "tick": tick}`
   ทำงานเพราะ `&GameTick` ก็ impl `Serialize`.
5. **Note ติด todo**: GSI parser เดิมตั้ง `in_game=true` ตั้งแต่ state INIT — log
   จับเหตุการณ์ pre-game 1 บรรทัด. แก้ใน `gsi.rs:58` ภายหลัง (ตัด INIT/
   HERO_SELECTION/STRATEGY_TIME ออก).
