# CONTEXT: BA and PO Requirement Guidance

## Context-Only Status

BA and PO guidance is context-only in Visual Agent Fleet v1. It informs LYRA, THESEUS, ATHER, GHOST, and RKOI, but it does not create a standalone BA agent yet.

## PO Decision Guidance

PO decisions should consider:

- Business goal.
- User value.
- Data or feedback.
- Effort and feasibility.
- Risk and dependency.
- What moves out if this enters the current scope.

## BA Requirement Guidance

Requirement work should clarify:

- Business need.
- System behavior.
- Required data.
- Workflow and exceptions.
- Scope and out-of-scope.
- Acceptance criteria.
- Traceability to test case and UAT.
